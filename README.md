# 🐶 Dog Nutrition Mobile Application

A mobile application designed to help dog owners explore and manage dog food and nutrition products through a simple and user-friendly interface.

## 📱 Project Overview

The Dog Nutrition application provides users with a convenient platform to browse dog food products, view product details, manage their shopping cart, and access useful nutrition-related content.

## ✨ Key Features

- User Registration & Login
- User Profile Management
- Browse Dog Food Products
- Product Details & Pricing
- Product Reviews
- Shopping Cart
- Order Management
- Product Filtering & Sorting
- Dog Nutrition Educational Content
- Location Support

## 🛠️ Technologies Used

- Java
- Android Studio
- Android SDK
- SQLite Database
- Gradle
- XML
- GitHub
